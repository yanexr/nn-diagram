nn-diagram

A JSX-based diagram format with a visual editor, CLI, and interactive React viewer.

Each diagram is a plain text file (*.diagram.jsx) written with JSX and Tailwind classes. Every element has explicit coordinates, so the layout in the file matches what is rendered. Shapes can carry hover notes in Markdown and LaTeX, diagrams can have walk-through steps, and exports are SVG, PDF, PNG, JPEG, and WebP.

With an AI agent

Install the skill, then ask your agent to draw or edit *.diagram.jsx files.

npx skills add yanexr/nn-diagram

In Claude Code you can also add it as a plugin: /plugin marketplace add yanexr/nn-diagram. npx nn-diagram skill copies the skill into .agents/skills/ of your project.

Open the same file in the editor (File → Open) to adjust it by hand. In Chrome and Edge the editor saves back to the file and reloads it when the agent changes it.

Command line

npx nn-diagram check diagrams/           # find errors
npx nn-diagram render flow.diagram.jsx   # PNG next to the file
npx nn-diagram render flow.diagram.jsx -f svg -t dark
npx nn-diagram fmt diagrams/             # rewrite in the standard form

Rendering uses an installed Chrome, Edge or Chromium.

In a React app

npm install @nn-diagram/viewer katex
import { DiagramViewer } from "@nn-diagram/viewer";
import "@nn-diagram/viewer/styles.css";
import "katex/dist/katex.min.css";

<DiagramViewer source={text} />

The editor works the same way:

import { DiagramEditor, DEFAULT_LIBRARY } from "@nn-diagram/editor";
import "@nn-diagram/editor/styles.css";

<DiagramEditor libraries={[...DEFAULT_LIBRARY, mySection]} onSave={(source) => store(source)} />

Both come with a neutral look in light and dark mode. To match your site's colors, font and corner radius, set a few CSS variables, for example: 

:root {
  --primary: #4f46e5;       /* buttons and highlights */
  --radius: 0.5rem;         /* corner radius */
  --font-sans: "Inter", sans-serif;
}

Dark mode follows the dark class on <html>. The variables are the ones shadcn/ui uses (--background, --foreground, --border, …), so a shadcn site matches without any changes.
